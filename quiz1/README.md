# Quiz 1 Deliverables

This directory contains the non-code submission assets for Quiz 1.

## Files

- `functional-requirements.txt`: short functional requirements list from Task 1.1
- `contact-domain-model.svg`: editable UML/domain model source
- `contact-domain-model.png`: image deliverable for Task 1.2
- `contacts-sorted.json`: JSON output generated by the CLI app in Task 2.4
- `screenshots/`: place the required evidential screenshots here before submission

## Code Location

The Java CLI application for Quiz 1 is implemented in:

```text
src/main/java/edu/miu/cs/cs489appsd/quiz1/contactscli
```

## Run

```bash
mvn -q -DskipTests package
java -cp target/classes edu.miu.cs.cs489appsd.quiz1.contactscli.ContactsApp
```
