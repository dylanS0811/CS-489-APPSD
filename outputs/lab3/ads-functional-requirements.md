# Lab 3: Advantis Dental Surgeries (ADS) Functional Requirements

1. The system should allow the Office Manager to register dentists in the ADS network.
2. The system should record each dentist's unique ID, first name, last name, contact phone number, email, and specialization.
3. The system should allow the Office Manager to enroll new patients who require dental services.
4. The system should record each patient's first name, last name, contact phone number, email, mailing address, and date of birth.
5. The system should allow patients to request appointments by phone through the Office Manager or by submitting an online form on the ADS website.
6. The system should allow the Office Manager to book appointments for patients.
7. The system should record each appointment's date and time, patient, dentist, and surgery location.
8. The system should send a confirmation email to the patient after an appointment is booked.
9. The system should allow dentists to sign in and view all of their appointments together with patient details.
10. The system should allow patients to sign in and view all of their appointments together with dentist information.
11. The system should maintain information about each surgery, including its name, location address, and telephone number.
12. The system should allow patients to request cancellation of an existing appointment.
13. The system should allow patients to request a change to an existing appointment.
14. The system should prevent a dentist from being assigned more than five appointments in a given week.
15. The system should prevent a patient from requesting a new appointment when the patient has an outstanding unpaid dental-service bill.
